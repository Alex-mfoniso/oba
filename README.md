# Book Library API

A simple Django REST Framework project for managing books and authors.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run migrations.
4. Start the development server.

## API

- `GET /api/books/`
- `POST /api/books/`
- `GET /api/books/<id>/`
- `PUT /api/books/<id>/`
- `PATCH /api/books/<id>/`
- `DELETE /api/books/<id>/`
